## ⚡ Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/SaiyamJain468/Ecolearn.git
cd Ecolearn

# 2. Install dependencies
cd apps/web-admin
npm install

# 3. Launch development server
npm run dev
```

> 🟢 Open **http://localhost:5173** — Auto-logged in as **Admin (Demo User)**

## 🎨 Design Philosophy

- **Cinematic Dark UI** — Deep space-grade dark theme with glassmorphism
- **Neon Accent System** — Cyan (`#00F2FE`), Emerald (`#10B981`), Amber (`#F59E0B`)
- **Micro-Animations** — Every interaction has spring-based motion feedback
- **Cursor Spotlight** — Ambient glow follows cursor movement
- **Floating Particles** — Reactive particle system in the background
- **Toast Feedback** — Every button provides instant, styled notifications
